# AtmProcess 使用说明

AtmProcess 是用于科研实验的 Windows 图像处理程序，支持液膜尺寸与破碎长度测量、平均图、彩色转灰度、火焰锥角和雾化锥角处理。界面可切换中文和英文。

程序附带编号29的20张雾化图像、提取参数和演示汇总表。第一次使用可以直接调参、计算和导出，不必先准备自己的实验数据。样例仅演示操作流程，不代表完整实验或论文全部结果的复现。

## 1. 下载与准备

1. 下载仓库 ZIP 并**完整解压**到可写的本地文件夹，不要在压缩包内直接运行。文件夹可以保留 `AtmProcess-main` 等名称。
2. 安装64位 Python 3.10或更高正式版，包含 pip 和 Tcl/Tk。安装程序及说明见 [Python Windows 下载页](https://www.python.org/downloads/windows/)。确保 `py` 启动器或 `python` 命令可用。
3. 配置依赖时需要网络连接。结果表自动打开需要系统已关联 `.xlsx` 文件的应用；若需自动保存、关闭已打开的目标工作簿，需使用桌面版 Microsoft Excel。

安装脚本不会安装 Python 本身，也不会安装 Excel。不同 Python 版本和依赖组合未全部进行兼容性测试；依赖清单见 [requirements.txt](requirements.txt)。

## 2. 一键配置与启动

**首次使用：双击 `setup_env.bat`。** 脚本在当前程序目录创建 `.venv`，安装所需依赖。看到 `Setup complete` 后关闭该窗口。

**日常使用：双击 `start.bat`。** 启动脚本始终使用本目录的 `.venv`，不用手动激活环境或输入命令。正常退出程序后，启动窗口会关闭；出错时保留错误信息。

项目环境与其他 Python 项目的依赖隔离，不修改全局依赖。配置失败时可根据提示处理后重新运行 `setup_env.bat`；它不会清空实验数据或本机设置。有关独立环境的机制见 [Python venv 说明](https://docs.python.org/3/library/venv.html)。

已经有可用 Python 环境的用户，也可以在程序目录手动运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 3. 先运行雾化锥角样例

### 单张调参

1. 首次打开时，程序进入“雾化锥角”页面，实验编号为29，帧范围为8000–8019。
2. 右侧显示当前图像，左侧显示提取参数、锥角结果及四张面积加权灰度曲线。
3. 修改参数后**按回车**，提交数值并重新计算。仅在输入框中打字不会触发延迟计算。
4. 用“当前帧”后的 `-`、`+` 切换图像；也可以设置播放帧率并点击播放。计算速度会限制实际播放速度。
5. 预览中的计算区域、锥角线等开关可以同时勾选。颜色反转、显示二值化只是显示选项，不改变计算参数。

### 批量处理与汇总

1. 默认帧范围覆盖全部20张样例，抽帧间隔为1。
2. 点击“批量处理雾化锥角”，等待进度完成。
3. 程序导出逐帧结果、统计量及频域数据，并把提取参数、角度平均值和标准差写入演示汇总表中**编号为29的记录**。

默认输出位置：

| 内容 | 程序目录下的路径 |
| --- | --- |
| 批量结果 | `sample_data/results/实验编号29_雾化锥角批处理结果.xlsx` |
| 演示汇总表 | `sample_data/results/atomization_summary.xlsx` |
| 预览图 | `sample_data/results/preview/` |

四张灰度曲线也可分别导出 Excel 数据，使用雾化页面中的结果目录。预览图使用右侧设置的保存目录和文件名。

### 如何理解演示汇总表

汇总表沿用2023年4月15日原始实验表的布局：左侧保留喷注盘、压力、流量、图像范围等工况字段与相关公式，右侧为雾化提取参数和结果。已删除破碎长度区域、其他实验记录和无关工作表。

- 第1行是字段名称，第2行保留原表单位及校准、修正信息，第3行是唯一的编号29工况记录。
- 程序按“编号”查找工况，按标题查找参数位置；不是按 Excel 第29行或固定列字母写入。
- 左侧原始范围为21000–21520帧，内置演示实际处理8000–8019帧。两者用途不同，备注中已注明；本次处理结果对应的帧号以批量结果表为准。
- 历史锥角结果已清空，避免把旧统计值误认为这20张图的结果。保留的 `*RevStd` 原表字段目前不由汇总写入流程填充；相对标准差可在单独批量结果表中查看。
- `RStartL`、`RStartR` 分别位于对应 `NumAvgL`、`NumAvgR` 之后。

首次启动会把随程序发布的模板复制到结果目录。之后只写结果副本，不改原模板，也不覆盖已经存在的结果副本。单张预览用于调参，不会每刷新一次就改写汇总表。

## 4. 处理自己的数据

1. 选择“数据根目录”，例如该目录下包含 `实验编号29`、`实验编号30` 等子文件夹，图像名称使用可识别的帧编号。也可使用界面提供的直接图像来源选择。
2. 输入实验编号并按回车，确认图像来源、帧范围和当前帧。
3. 设置抽帧间隔。例如从202开始、间隔为2，处理集合为202、204、206……；切帧按钮和批量任务均遵守该集合。
4. 切换到需要的功能页，设置标定和处理参数，先检查单张图像效果，再执行批量操作。
5. 为自己的实验选择独立的结果目录和汇总表，不要继续把演示表当作真实实验的汇总表。

自己的汇总表可参考演示表布局：第一行保留程序识别的字段标题，工况行使用唯一实验编号。可在雾化页面点击读取参数按钮，从所选汇总表恢复当前实验的提取参数。汇总表留空时仍可计算和导出独立结果，但不进行汇总写入，也不能从汇总表读取参数。

频域计算使用页面输入的图像帧率。应填写**参与处理的图像序列的采样频率**；若先做了抽帧，需要自行填写对应的有效频率，程序不会再自动除以抽帧间隔。

## 5. 其他功能

| 页面 | 基本用途 |
| --- | --- |
| 液膜测量 | 在液膜尺寸和破碎长度两种模式中选择一种，点击预览设置边界，实时显示结果，记录逐帧数据并导出 Excel；也可读取已导出的记录。 |
| 平均图 | 按所选帧集合生成平均图，或将彩色图批量转换为灰度图。 |
| 火焰锥角 | 查看单帧效果、调整参数并批量提取火焰锥角。 |
| 雾化锥角 | 单帧调参、灰度曲线检查、批量提取和汇总表读写。 |

液膜测量切换实验编号或图像来源时会清空当前记录表，请先导出需要保留的数据。平均图、灰度转换等操作可能生成或覆盖输出图像，首次处理自己的数据前应保留原图备份。

## 6. 设置、文件与常见问题

- **下次打开还会回到样例吗？** 不会强制回到样例。关闭时保存 `settings.json`，下次恢复上次的页面、路径、参数和预览选项。
- **如何重新体验首次启动？** 使用新的解压文件夹最直接。也可在关闭程序后先备份并移走 `settings.json`。已有结果副本不会因此被清空。
- **安装失败怎么办？** 保留窗口中的错误信息，确认网络、Python版本以及目录可写，再运行配置脚本。不要把项目放在需要管理员权限才能写入的位置。
- **启动提示先配置环境？** 先双击 `setup_env.bat`。仅在系统 Python 中安装依赖，不代表本目录 `.venv` 已配置。
- **移动文件夹后启动失败？** 程序和设置可以迁移，但 `.venv` 不应直接跨路径或跨电脑复用。关闭程序，移走旧 `.venv`，在新位置重新运行配置脚本；保留 `settings.json` 和结果文件。
- **Excel 被占用怎么办？** 程序只尝试保存、关闭与目标路径一致的 Excel 工作簿，不退出 Excel、不处理其他工作簿。若被 WPS 或其他应用占用，请手动保存并关闭目标文件后重试。
- **文件写入成功但无法自动打开？** 为 `.xlsx` 设置默认打开应用。自动打开失败可能中断后续汇总步骤，应检查汇总表是否更新，解决关联问题后重试。
- **样例是否提供完整论文数据？** 不提供。样例来源、位深和文件校验信息见 [样例说明](sample_data/README.md)。
